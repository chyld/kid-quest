# Kid Quest

- clone repo

## Requirements

- uv
- node
- tmux

## Backend

- add reward.txt; set initial value
- `./start.sh`
- http://localhost:8000/docs

## Frontend

- `npm install`
- `npm run dev`
- http://localhost:5173/

## Permissions

- `sudo visudo`
- `%sudo   ALL=(ALL:ALL) ALL, (ALL) NOPASSWD: /sbin/iptables, /sbin/ip6tables`

## GUI

- `uv sync`
- `uv run main.py`
